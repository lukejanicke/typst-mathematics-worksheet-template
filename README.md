# Typst Mathematics Worksheet Template

A simple Typst template for mathematics worksheets, with clear numbering, space for working, and optional answer keys and worked solutions.

The A4 layout includes a title and name field, flexible columns for question parts, optional marks and page numbers, and support for ordinary Typst diagrams, tables, and graphs. Worksheets export as PDFs for printing or digital annotation.

Developed and verified with Typst 0.15.1.

## Examples

- **Example** — [PDF](examples/Example.pdf) · [Typst source](examples/Example.typ). Demonstrates question and sub-part numbering, columns, shared instructions, working space, marks, figures, tables, graphs, and complete answer and solution sections.
- **Subsets Example** — [PDF](examples/Subsets%20Example.pdf) · [Typst source](examples/Subsets%20Example.typ). Demonstrates selected answers and solutions, omitted entries, explicit numbering references, and counter resets.
